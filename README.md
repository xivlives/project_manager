## PROJECT-MANAGER
this is something i planned would be avaiable for student use.
## HOW DOES IT WORK?
you can use this tool to track your different learning and work related projects. you can also track your tasks in those different projects and this helps keep projects organized.
## TECH STACK
MERN- MongoDB, Express, ReactJs and NodeJs, MYsql
the codebase is divided into two segments
# frontend: 
this is all the client side related code involving apis, designs, and components based structure 
# backend
this is all the server side coded that involves models for data stored in db, classes with accompanying functions then api routes
